# Adaptadores por instituição

Cada subpasta aqui está reservada para o futuro adaptador de integração
oficial (Open Finance) da respectiva instituição — responsável por traduzir
os dados retornados pela API do Open Finance para o formato interno de
`contas` e `transacoes` do FinanHub.

Nenhum adaptador deve, em nenhuma hipótese, solicitar ou armazenar a senha
bancária do usuário: a autenticação acontece inteiramente no fluxo oficial
de consentimento do Open Finance, fora do FinanHub.

Enquanto as integrações reais não existem, todo o app funciona com o
**modo demonstração** (dados fictícios).
